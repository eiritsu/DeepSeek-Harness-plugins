## 快速上手

1. **浏览与搜索技能**：从侧边栏底部「技能库」或 **插件 → 技能** 页面打开社区技能目录，默认即可浏览 `sickn33/agentic-awesome-skills` 精选库，并实时联合检索 `skills.sh` 热门榜单。
2. **筛选与预览**：支持在「全部双源」「GitHub 精选库」「skills.sh」间切换，按分类胶囊与排序（综合排序 / 安装量 / 最近收录）筛选；点开条目可查看解析后的 GitHub 仓库路径、Commit SHA、文件清单与完整 `SKILL.md` 内容。
3. **校验与安装**：二次确认后将按审查通过的 40 位 Commit SHA 拉取全部文件、逐个校验 Git blob 哈希并通过 DSH 文件系统技能规范检查后，原子安装至全局 DSH 技能目录。
