## Quick Start

1. **Search Skills**: Search SkillsMP in the Community Skill Catalog using keywords (e.g., git, react, python).
2. **Preview & Install**: Click a skill to preview its instructions, then click **Install** to pin and install it to your profile.
3. **Use Skills**: Once installed, the agent can automatically discover and use the skill during sessions.
