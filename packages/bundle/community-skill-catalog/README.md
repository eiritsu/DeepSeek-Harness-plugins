## Quick Start

1. **Browse or Search Skills**: Open the Community Skill Catalog from the sidebar footer or the **Plugins → Skills** page to browse indexed skills from `sickn33/agentic-awesome-skills` and search live popularity rankings on `skills.sh`.
2. **Filter & Preview**: Switch between `All sources`, `GitHub index`, and `skills.sh`, filter by category pills, sort by popularity/installs/recent additions, and open any item to inspect its resolved GitHub repository path, commit SHA, file inventory, and `SKILL.md`.
3. **Verify & Install**: Confirm installation to fetch files pinned to that exact commit SHA, verify Git blob hashes, validate with DSH's filesystem skill loader, and install into your global DSH skills folder.
