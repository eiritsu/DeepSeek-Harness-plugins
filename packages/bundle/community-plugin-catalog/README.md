## Quick Start

1. **Browse Plugins**: Open the Community Plugin Catalog from the sidebar to discover community plugins.
2. **One-Click Install**: Click **Install** on any plugin card; confirm in the dialog to automatically download and link the package.
3. **Activate**: After installation, enable the plugin under the **Plugins** management list.
