## Quick Start

1. **View Schedule**: Open the Calendar view from the sidebar to inspect scheduled automations and local calendar entries.
2. **Add / Subscribe**: Create local calendar entries or subscribe to external iCalendar (.ics) feeds.
3. **Automate**: Pair with Schedule automations to coordinate recurring agent tasks.
