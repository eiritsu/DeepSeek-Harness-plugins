## Quick Start

1. **Choose Setup Path**: Select **Quick connect** (official device authorization) or **Use an existing app** (manual App ID and Secret).
2. **Authorize**: Follow the prompt to complete authorization in your Lark or Feishu client.
3. **Enable Connection**: After setup succeeds, toggle the switch in the top-right corner to start chatting with the agent via private messages.
