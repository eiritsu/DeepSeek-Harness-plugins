# @deepseek-ai/dsh-purge

English | [中文](README.zh.md)

DeepSeek Harness cybersecurity evaluation, prompt injection, and red-team drill suite for DeepSeek Harness `0.2.2-rc.1`.

## Features

- **Prompt Injection & Rules**: Custom rule sets and session prompt overrides per model, stripping unnecessary system boilerplate.
- **Red-Team Drill Platform**: Built-in red-team facts store (SQLite), scenario execution, asset tracking, and evaluation tools.
- **Interactive UI**: Clean & Drill docks integrated into Web and Desktop clients.
- **Defensive Capability Protocol**: Discovers matching host skills and MCP tools dynamically without intrusive modifications.

## Upstream Attribution

This bundle adapts the open-source cybersecurity red-team plugin `dsh-purge` (originally by YuJunZhiXue and mirrored by mmparko) to the DeepSeek Harness `0.2.2-rc.1` plugin standard. Upstream licenses and notices are preserved in `LICENSE` and `MIRROR-NOTICE.md`.
