# @deepseek-ai/dsh-purge

[English](README.md) | 中文

适用于 DeepSeek Harness `0.2.2-rc.1` 的网络安全评测、提示词设定注入与红队演练套件。

## 功能特性

- **提示词注入与规则设定**：支持按模型配置自定义规则集与会话提示词注入，按需剥离冗余系统模板。
- **红队安全演练台**：内置红队事实库（SQLite）、演练预设、资产追踪以及安全评测工具。
- **双端交互界面**：在 Web 端和 Desktop 端均集成「清洗」与「演练」专属侧边抽屉面板。
- **能力选用协议**：智能感知并按需选用会话内适用的 Host 技能与 MCP 工具，不侵入官方基础注册。

## 上游署名与来源

本插件由开源安全演练插件 `dsh-purge`（原作者：YuJunZhiXue，镜像来源：mmparko）适配至 DeepSeek Harness `0.2.2-rc.1` 插件规范。完整开源协议与镜像说明保留于 `LICENSE` 与 `MIRROR-NOTICE.md`。
