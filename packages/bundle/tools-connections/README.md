## Quick Start

1. **Open Settings**: Navigate to **Tools & Connections** under the **Plugins** list.
2. **Configure Search**: Enter your Brave Search or Tavily API key to enhance web search capabilities.
3. **Configure Extraction**: Enter your Firecrawl API key to enable high-fidelity web page extraction and Markdown scraping.
4. **Save**: Save your credentials; the agent will automatically use the active providers for search and extraction tasks.
