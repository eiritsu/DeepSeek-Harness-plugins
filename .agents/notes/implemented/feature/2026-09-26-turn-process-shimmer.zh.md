# Agent Note: Optional turn-process shimmer renderer

Status: implemented

[English](2026-09-26-turn-process-shimmer.md) | 中文

## 问题

rc2 运行中轮次的标签没有闪烁效果，而冻结版客户端样式记录了独特的品牌蓝色移动高光。若在 `ui-chat` 或默认 profile 中恢复该样式，会让可选视觉偏好影响官方客户端。

## 决策

独立 Client 插件替换 `conversation.chat.node` 中注册为 `turn-process` 的关键渲染器。它只在所属轮次运行时添加 CSS 文字闪烁，并保留官方标签状态、时长、披露、点击、aria 和本地化行为。启用减少动效的用户看到静态品牌蓝色标签。默认 profile 和已发布的 Web bundle 均不包含此插件。

## 考虑过的替代方案

- **修改官方 `ui-chat` 渲染器：**不采用，因为这会让可选视觉效果成为默认行为，并修改官方包。
- **复制冻结版组件结构：**不采用，因为冻结版仅作为视觉参考，不能代表 rc2 当前的 Slot 和交互行为。
- **在官方 key 旁注册另一个渲染器：**不可行，因为关键槽对每个 key 只允许一个渲染器；替换是受支持的注册方式。

## 后果

插件在本地保留少量时长与披露辅助函数，以避免运行时依赖另一个功能插件。使用者必须显式启用，并确保插件在官方渲染器之后加载。插件激活时，关键槽不会再选择官方渲染器；聚焦测试覆盖保留的行为和呈现。
